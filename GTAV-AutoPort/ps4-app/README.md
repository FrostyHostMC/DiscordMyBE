Native AutoPort PS4 homebrew application. The controller-driven UI browses `/mnt/usb0`, `/mnt/usb1`, `/data`, and the staged import library at `/data/AutoPort/imports`. It inventories GTA V resources, configuration files, RPF archives, PC plugin binaries and GoldHEN PRX files for intake. Select a file to copy it into `/data/AutoPort/imports`; imports use a temporary `.part` file, verify copied byte count, flush and atomically rename into place, avoid overwriting existing imports, and append a JSONL receipt. The original source file and GTA V game files are never modified. This milestone stages files only: it does not unpack archives, convert PC resources, install AFR overlays, modify `plugins.ini`, or patch GTA V. Build requires OpenOrbis v0.5.4 and produces an unsigned homebrew PKG for a GoldHEN-enabled PS4. Console behavior remains untested until a user chooses to test it.
