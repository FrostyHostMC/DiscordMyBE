Native AutoPort PS4 homebrew foundation. Uses OpenOrbis VideoOut for a 1080p controller-operated file browser. Browse /mnt/usb0, /mnt/usb1 and /data; import selected RPF, ZIP, 7Z, OIV, YFT, YTD, YDD, YDR, META, XML, INI and TXT files to /data/AutoPort/imports. Source files and GTA V game files are not overwritten. This first milestone stages files only; it does not convert PC resources, install AFR overlays, modify plugins.ini, or patch GTA V. Build requires the OpenOrbis PS4 toolchain and packages an unsigned homebrew PKG for GoldHEN-enabled consoles.
